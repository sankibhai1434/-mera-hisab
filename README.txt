MERA HISAB — Android installable web app

Files:
- index.html: app
- manifest.json: install metadata
- sw.js: offline cache
- icon-192.png, icon-512.png: app icons

To install on Android:
1. Upload these five files to a public HTTPS static host (for example GitHub Pages).
2. Open the published HTTPS URL in Chrome on Android.
3. Tap Chrome menu (⋮) > Install app / Add to Home screen.
4. Confirm installation.

Data is stored in browser localStorage on this device. Use Report > पूरा बैकअप डाउनलोड करें regularly. Restoring a backup replaces current records. Clearing browser site data can erase saved records. This package is a Progressive Web App (PWA), not a signed APK.
